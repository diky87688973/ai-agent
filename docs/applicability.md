# 标准适用性申报

本仓库当前**不申报任何不适用项**：`production-standards.md` 的条目全部按标准执行。
缺省即适用，新增豁免必须在下表补一行，并写清原因与风险承担者。

| 准则 | 申报 | 原因 | 风险由谁承担 |
|---|---|---|---|

## 维护约定

1. 只能申报 `MUST` / `SHOULD` 条目；不申报等于该条目继续生效。
2. 原因必须是一句能独立读懂的话，至少 20 字；"本项目不需要"不算原因。
3. 风险承担者必须写具体角色或"无（不存在该风险）"；不允许留空。
4. 标准手册里的编号变化时，本表按编号双向比对：手册有而本表没有 = 继续适用；
   本表有而手册没有 = 过期申报，门禁报错。
5. 本地需要做完整编号比对时，把手册路径给 `STANDARDS_DOC`：

   ```bash
   STANDARDS_DOC=/path/to/production-standards.md python scripts/check_applicability.py
   ```

   未设置该变量时门禁只校验结构，并在输出里明确写"ID 覆盖与占比未验证"。
