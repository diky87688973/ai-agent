# 插件 2.0 热插拔

## 目标与归属

插件的声明、工具、上下文源、提示词、事件、路由、设置、界面与运行时资源作为同一代发布。关闭、重新启用、保存配置、重新加载源码和移除目录均通过该发布流程。

`agent/core/slot_lifecycle.py` 持有活跃读取租约与待应用请求。它不识别具体插件或壳层。`agent/core/slot_assembly.py` 负责依赖构造、未受影响节点复用与资源释放。`agent/boot/plugin_runtime.py` 是组合根的代切换协调者，调用片段解析、装配、绑定与模型策略。插件私有资源由其运行时的 `dispose()` 释放。

`SlotAssembly.config` 与构造值是当前代的装配来源，`SnapshotStore` 提供冻结副本。工具、UI、设置和上下文登记是该代向既有消费接口的投影，由 `SlotBinder` 的撤销句柄重建。插件不再通过代码注册通道另建能力清单。旧后端路径种子表已移除。

## 启用清单与来源

默认清单允许发现目录自带的声明插件，显式 `enabled=0` 优先。指定独立清单时按完整配置剖面处理，未列出的普通目录补为禁用，显式声明 auto_load 的插件保留自动装载语义，避免验收或无头实例意外接入开发机的模型配置。继承剖面先由既有配置解析器展开。

启动与重载都使用同一份解析后的清单。清单中 `path` 指向的实际插件目录通过 `SlotConfig.plugin_roots` 传递给片段、工厂与环境解析。该字段记录外部来源，无法由插件名和默认插件根推导。路径信任策略在执行插件工厂之前检查。

关闭一个挂载点提供者后，其他插件对它的贡献休眠。提供者恢复后，贡献随完整声明重新求值。未声明的宿主路径仍然报错。`web_ui` 是纯声明插件，以 `plugin-meta.json` 识别，默认开启。

## 切换顺序

1. 读取并校验候选片段，形成有效配置。
2. 空闲时立即切换。有活跃回合或插件 HTTP 请求时登记待应用请求，全部读取者退出后按请求顺序应用。
3. 保存旧插件身份和模块对象，撤回旧登记，构造候选节点。声明、依赖与来源不变的节点复用现有实例。显式重载的插件及其依赖受影响节点重新构造。
4. 登记候选工具、路由、事件、上下文、设置和 UI。任何绑定失败使本次发布失败。单条错误会收集进绑定报告，应用装配入口不接受部分登记结果。
5. 成功后发布新配置和构造值，推进快照版本，释放旧代中被替换的资源，广播插件列表变更。
6. 构造、模块加载或登记失败时撤回候选登记，恢复内存中的旧身份和旧模块，重新登记旧构造值，释放候选资源并报告错误。恢复不依赖已经修改或移走的旧源码。

回合租约覆盖引擎事件流，Web 会话运行器在构造提示词之前取得租约。无头入口使用同样的轮次保护。插件 HTTP 端点在响应结束后释放租约。普通 SSE 订阅不长期占用租约。

磁盘片段在启动与显式重载请求时读取。空闲轮次不重复扫描目录。物理目录增删后通过重载请求更新有效树。

## 边界与失败

热插拔保留宿主服务实例。修改宿主服务声明时拒绝本次热重载，宿主实现的启动覆盖仍通过既有覆盖协议装配。正在执行的回合不会因插件禁用而立即释放其资源。

延迟请求返回待生效说明，实际切换失败进入结构化错误日志，当前代保持可用。同步开关失败时清单恢复原文。配置保存与运行时切换分别保留错误报告。

CLI 与无头剖面的语音关闭节使用 `ai_cosplay`。`gen_catalog.py` 的装配使用临时数据根，并在返回前释放应用。

## 自动回归

`tests/test_plugin_hotplug.py` 覆盖以下行为。

- 禁用并重新启用后工具恢复，宿主上下文对象保持一致。
- 纯声明插件可启用。
- 并发读取者退出后才应用变更，多个请求最终达到最后请求状态。
- 工厂缺失、重复工具登记失败时恢复旧代。
- 同长度源码修改可在同一进程重载。
- 独立清单的禁用条目不构造工具。
- 目录移除后资源和身份撤回。
- 外置路径的声明与工厂来自同一目录，受目录信任策略约束。
- 快照容器拒绝写入。
- 真实 `web_ui` 连续关闭、重新启用，未受影响的技能实例保持一致。

`scripts/acceptance_phase3.py` 验证全开、全关、热卸三态的事件、上下文、UI、路由与冒烟回合。UI 断言读取消费端使用的 `ui.catalog()`，全开夹具显式包含 UI 挂载点提供者。

集成验证使用临时数据根、临时插件清单和本机 HTTP 服务。浏览器检查关闭与启用 API、刷新后的页面、设置列表和未捕获脚本异常。截图与详细命令结果保存在本次工作输出中。

## 验证要求

运行受影响的插口、插件、设置、入口和 Web 测试，再执行 `python scripts/ci.py --keep-going`。同步工具目录、用例文档、复杂度文档及 README 的实际计数。所有通过数、失败数、跳过数以当次执行结果为准。真实模型与真实语音效果需要独立环境验收。
