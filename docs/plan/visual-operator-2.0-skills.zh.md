# 视觉操作 2.0 Skills 操作指引

## 1. 启动

需要视觉时，先申请授权：

```text
vision_request_open
```

工具会返回固定授权卡片。用户通过输入区眼睛按钮旁的确认卡选择：

```text
同意
拒绝
```

用户点击同意后，模型会拿到一次性 `consent_id`，再调用：

```text
vision_start(consent_id="consent_...")
```

没有 `consent_id` 不得调用 `vision_start`。用户拒绝后不要继续重试同一个请求。

## 2. 观察

视觉启动后，每次模型请求的尾部会自动带上两张图：

```text
完整图：全屏状态
聚焦图：鼠标附近区域
```

模型不需要调用看屏工具，也没有独立截图工具。

观察文字会说明：

```text
帧时间
鼠标位置
鼠标是否在聚焦区域内
最近动作
```

鼠标不在聚焦区域时，以完整图为准，不要假设聚焦图里一定有鼠标。

每次模型请求前，同一个观察帧会通过 SSE 推送到前端：

```text
视觉帧  frame=f-...  age=...ms  cursor=(x,y)  scale=...
```

点开工具壳可以看完整图和聚焦局部图；这是模型实际收到的那一帧。

## 3. 聚焦

需要放大某块区域时：

```text
vision_focus(region={"x":...,"y":...,"width":...,"height":...})
```

需要把鼠标移到区域中心时：

```text
vision_focus(region={...}, center_cursor=true)
```

聚焦只影响第二张图，不影响完整图。

## 4. 操作

精确操作使用屏幕绝对坐标：

```text
vision_move_to(x=..., y=...)
vision_click_at(x=..., y=...)
```

坐标来自完整图，不要用鼠标局部图的像素，也不要用相对位移累加。

兼容的相对移动：

```text
vision_move(dx=..., dy=...)
```

确认坐标后点击：

```text
vision_click_at(x=..., y=..., count=1)
```

`vision_click` 只点击当前鼠标位置，不接收坐标。

多个不同坐标一次点完：

```text
vision_click_sequence(
  points=[{"x":320,"y":260},{"x":420,"y":260}],
  interval_ms=60
)
```

坐标同样来自完整图。批量选牌、连续按钮和列表操作不要拆成多次工具往返，也不要用 shell 或 python 代替。

等待动画或加载：

```text
vision_wait(ms=800)
```

不要用 shell sleep 代替。

键盘：

```text
vision_key(keys=["ctrl","c"])
```

## 5. 闭眼

模型主动闭眼：

```text
vision_stop
```

用户点击输入区的眼睛按钮也会闭眼。

闭眼后：

```text
停止采集
清空帧队列
清空待注入观察
不再注入视觉帧
```

用户手动移动鼠标、点击或按键时，系统立即闭眼并收回控制权；除 `vision_request_open` 外，视觉工具全部拒绝，必须重新申请授权。

眼睛打开时屏幕正上方显示 `[AI控制中]`；接管后前端显示 `已归还用户控制` 工具壳。

## 6. 多个会话

视觉资源全局唯一，同一时间只有一个会话持有：

```text
会话 A 已持有
会话 B 申请视觉
→ 明确返回“眼睛正被其他会话使用”
```

只有当前 owner 会话能读取视觉帧和操作视觉。

## 7. 失败处理

```text
没有 consent_id：先调用 vision_request_open
用户拒绝：不要继续申请，等待用户下一步
眼睛被占用：等待 owner 闭眼或切换会话
鼠标不在聚焦区域：看完整图
点击无变化：重新观察，不要连续盲点
```

## 8. 禁止

```text
不要调用看屏工具
不要使用 shell、UIA 或应用接口
不要伪造、复用或跨会话使用 consent_id
不要在眼睛关闭时操作
不要在未确认鼠标锚点时点击
```

## 9. 输入区眼睛按钮

```text
眼睛打开时显示
悬浮显示“模型已睁眼”
点击只关闭，不提供重新睁眼
重新睁眼只能走 vision_request_open
页面刷新读取一次状态
后续由 SSE eye_opened / eye_closed 更新
```
