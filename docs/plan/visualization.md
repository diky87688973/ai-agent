# 对话可视化

## 职责与扩展边界

目标是让模型在正常对话中调用 `visualize`，按任务需要生成图表、流程和可交互选项。用户可直接提出“画流程图”“用图表比较”“给我选项”等请求；模型通过工具说明获得类型、数据形状与修订规则，再沿既有工具管道产出面板。宿主上下文用量等内置仪表接入不属于本专项，也不是待完成项。

公共面板宿主位于 `agent/shell/web/ui/`，负责既有工具事实投影、修订选择、实现绑定、资源释放和本浏览器视图状态。`web_ui` 仅接入工具结果、会话归属及有效 UI catalog；组件适配、校验、样式和离线依赖全部归 `plugins/visualization/`。内核、ToolPipeline、SessionStore 不增加图表分支或可视化数据库。

展示扩展遵循 [插件插口协议 §2.5](plugin-slots-protocol.md)：插件通过 `ui-tool-shell` 的 `props.renderer` 声明类型；前端只能绑定有效目录中且 owner 匹配的类型。JS 注册不是第二条能力声明通道。公共宿主更换要求重启，插件贡献支持既有安全边界热插拔。独立插件验收不安装 visualization，仅添加自己的工具、片段和脚本即完成真实消息展示。

## 工具与事实契约

`visualize` 必填参数为 `{panel_id,revision,operation,kind,title,summary,data}`。成功结果包含 `display:{version:1,id,revision,operation,type,title,summary,data}`，其中 `type=visualization.<kind>`。ID 为会话内稳定的1–64位ASCII字母数字、下划线或短横线；修订从1开始连续递增，完全相同的最新修订重试幂等，冲突或跳号拒绝。`upsert` 创建或替换完整快照，`remove` 要求已存在未移除面板且 `data={}`，旧事实不改写。

修订权威来自所属会话的既有 `TOOL_DONE` 事实。宿主按会话和ID选择最高修订，旧修订显示已替换，重复事实不重复呈现，移除显示明确状态。恢复沿既有SSE/历史读取路径完成。未知协议、缺失实现和渲染异常仅影响当前面板，保留摘要与工具事实。无头入口获得相同工具结果及文字摘要。

标题1–120字，摘要1–2000字，标签最多160字，参数UTF-8 JSON最多64 KiB。数值必须有限、不是布尔且绝对值不超过1e100。拒绝未知字段、嵌套单元格、非法引用和未支持类型；输出为独立JSON快照。

## 组件与输入

| kind | data | 边界 |
|---|---|---|
| proportion | `{items:[{label,value}]}` | 横向堆叠条、原值和百分比；最多100项、非负，非空时总量大于0 |
| donut | `{items:[{label,value}]}` | 环形图；同上 |
| progress | `{items:[{label,value,total}]}` | 静态已知总量进度；0≤value≤total、total>0，最多100项 |
| tasks | `{batch,task_ids}` | 当前会话已有批次，1–100个唯一任务ID |
| flow | `{nodes:[{id,label}],edges:[{source,target}]}` | 1–60个唯一节点、最多120条合法引用边，支持回边 |
| mermaid | `{code}` | 仅flowchart与sequenceDiagram，最多16000字/150行 |
| bar | `{items:[{label,value}]}` | 最多100项，支持负值 |
| line | `{labels,series:[{label,values}]}` | 1–200点、1–8条线，维度一致 |
| table | `{columns:[{key,label}],rows:[{列key:标量}]}` | 1–20列、最多500行，精确列键；筛选、数值排序与行选择 |
| timeline | `{unit,events:[{label,at,detail}]}` | 最多100项，按时间排序，显式单位 |
| gantt | `{unit,tasks:[{label,start,end,status}]}` | 最多100项，start≤end，等待/运行/成功/失败/取消 |
| waterfall | `{unit,items:[{label,start,end,status}]}` | 同上，用于请求时间区间 |
| controls | `{fields:[{id,label,type,value,...}]}` | 1–12个唯一控件；select/tabs最多20选项，toggle布尔，range显式min/max/step且值对齐、最多1000000步 |

空集合展示空态，不伪造零值。图表值来自调用方提供的快照；上下文分配样例不代表接入了宿主真实token统计。

## 实时来源与依赖隔离

任务组件只读既有后台任务服务，使用明确任务列表为分母，区分等待、运行、成功、失败、取消；轮询串行且可取消，以当前快照避免增量事件乱序覆盖。失联显示连接错误并保留上次画面，重连重新同步；全部已知任务终态后停止轮询，非活动会话暂停请求，卸载取消请求与计时器。

后台任务服务当前为进程内权威：同进程刷新和重连可恢复终态，进程重启后来源已清除的任务显示不可用，不另建进度账本或伪造状态。跨进程任务恢复不属于图表插件可独立承诺的能力。

渲染职责交给成熟开源库：结构化flow与源码流程/时序统一使用Mermaid 12.3.0；比例、环形、柱形、折线、甘特和请求区间使用Apache ECharts 6.1.0标准pie/line/bar及堆叠bar系列。插件不维护SVG绘图、节点排布或连线路由，不使用custom系列绘图回调。进度、任务列表、时间列表、表格和表单采用语义化DOM。依赖随插件离线打包，来源、tarball完整性和文件哈希分别记于 `vendor/provenance.json` 与 `vendor/echarts/provenance.json`，许可证及NOTICE保留于对应目录。工具拒绝配置指令、HTML、链接、点击动作和样式注入；严格模式渲染并限制边数与体积，输出再次检查后置于无权限sandbox iframe，CSP禁止脚本与外部资源。结构化节点标签逐字符实体编码，节点ID由适配器生成，不把标签当图语法；该路径启用库的HTML文本标签以正确处理实体，输出foreignObject内部仅允许div/span/p/br。模型直接提供的Mermaid源码仍禁用HTML标签并拒绝foreignObject。坏图显示摘要和源码；依赖按需加载，失败只影响当前面板，不回退自绘。ECharts使用SVG渲染与richText提示，不接受模型提供option、formatter、JavaScript或HTML；配置由适配器构建。实例独立拥有库事件和ResizeObserver，更新、移除及卸载时释放实例、监听器与待执行帧，卸载后待加载任务拒绝继续。任意模型生成HTML/JavaScript未开放。

## 产品界面与模式

默认采用内容展示模式：标题、数据和必要图例，不展示筛选、缩放、重置、导出、类型徽章或空的操作页脚；摘要供无障碍阅读与无头入口使用，不在图旁重复一整段数据。图形默认只读，原生提示可查看数据。悬停或键盘聚焦时可找到宿主的轻量编辑入口。

视图编辑能力由每个渲染类型的 `props.editable:true` 声明，公共宿主通过 `context.mode` 管理。进入编辑后仅提供当前类型有效的操作：Mermaid不出现无效筛选或缩放，结构化流程不出现未支持的缩放，进度不出现缩放，导出与恢复默认收进更多菜单。编辑只改变本地视图；业务数据更新仍通过模型调用工具生成新修订，不暗改事实。退出和Escape收起操作，重载和新修订默认回到展示模式。

表单的选择交互与视图编辑不同：下拉、开关、分段选项和滑块在默认模式即可使用，也可确认默认值。选择通过明确的“添加到消息”操作进入普通输入框。控件标签和回传内容使用可读名称，不把true/false、选项内部ID作为用户文案。滑块拖动即时更新数值，提交变化后保留键盘焦点。

界面使用统一层级：15px标题、13px正文、12px辅助信息，默认24px内容边距、窄屏18px；选中行四周保留内边距，不让色块贴字。进度轨道6px，比例条16px且外端圆角；表格单元格12px×16px，线条只用于必要分组。主色为清亮蓝，数据序列以青、橙、紫等明快色区分；背景与分隔线保持中性。百分比最多一位小数且省略无意义的零。流程节点尺寸、文字排布和连线交由Mermaid统一处理；按钮与分段选项采用居中布局。

明暗主题共享相同尺寸与间距，仅切换配色；Mermaid从同一组设计变量取色、字体，主题改变时重新绘制。窄屏收起会话导航后验证320px内容布局，长图在自己的视口滚动。滚轮使用浏览器原生滚动链：内部无可滚动内容或已到边缘时继续滚动对话；Mermaid的只读sandbox iframe不参与指针命中，节点选择仍通过编辑态文字列表完成，不注入滚轮转发脚本。颜色、数字、文字状态和键盘反馈共同表达含义。

图形块使用平面外观、8px圆角和13px标签。时序参与者框144×40，显式采用Mermaid classic外观，避免默认外观额外堆叠标题高度；展示只允许缩小适配，不自动放大原始图形。两种流程入口共享Mermaid classic主题与直角曲线策略，不保留默认阴影；结构化分支、回边和自环均由库布局。编辑模式提供节点文字列表供键盘选择，展示模式隐藏该列表，sandbox内不执行点击脚本。统计图点击通过ECharts事件回传本地选择，另有编辑模式文字列表供键盘等效操作。

## 交互与生命周期

筛选、排序、缩放、选择和控件值是本浏览器视图状态，按会话和面板ID存于localStorage，包含格式版本和面板修订。刷新恢复同修订状态，新修订重置旧状态。未知或损坏格式显示重置提示，不静默兼容。跨设备不共享状态。

“加入输入”只写当前面板所属会话的普通输入框，用户正常发送后才进入模型。失效面板、旧修订、移除状态与会话不匹配拒绝写入；成功加入后禁用按钮，改变选择后可再次操作。消息失败、取消和工具权限继续走既有消息流程，不建立隐藏执行入口。

交互支持键盘点选、选项卡方向键、明暗主题与320px窄窗口。动态节点采用容器委托；图表提供摘要与文字详情，颜色不是唯一状态线索。JSON导出事实快照，有SVG的组件可导出静态SVG。PNG及独立HTML导出未提供。

展示模式不产生图形选中背景或详情页脚；编辑模式选中不对图形包围盒加矩形轮廓，节点、行和图例以留有内边距的浅色背景反馈，详情在实际选择后显示。键盘焦点独立提示，不与鼠标选中状态混用。

## 验证入口

测试使用临时数据根、隔离清单和本地脚本模型，不操作真实会话：

- `tests.test_ui_registry`：非法/重复类型与归属释放。
- `tests.test_display_assets`：共享资产缺失、空文件、语法错误的门禁负向测试。
- `tests.test_display_extension`：无visualization的第二个插件展示，拒绝未声明绑定。
- `tests.test_visualization`、`tests.test_visualization_extra`：schema边界、快照、修订和插件生命周期。
- `tests.test_visualization_renderers`：离线库加载失败隔离与重试、结构化节点文本防注入、悬停控件与图形的真实滚轮及长表格边缘滚动链。
- `tests.test_visualization_browser`、`tests.test_visualization_browser_extra`：真实工具管道到历史面板、组件交互、重复事实、修订、双会话、刷新、主题、窄屏、任务断线/取消/终态、Mermaid局部失败及卸载恢复。

Windows Chromium为自动回归平台。Windows原生WebView已用当前配置的真实模型完成17项指定展示任务：13类展示中，将Mermaid流程/时序分开，并将四种本地控件分别验收；每项保存浅色窗口截图，另保存一次选择回传后的模型回复截图。用户请求明确要求可视化，没有预填工具调用或渲染结果；该验收不等同于任意模型都能自行选择最合适的图表。

截图复核修正了结构化回边被节点遮挡、时序图内部裁切和环形图默认过大的问题，并补充了流程边字段、Mermaid样式限制及失败调用不递增修订的模型工具说明。macOS与Linux未验证。工程检查采用既有JS、插口、架构与文档门禁，生成物由原有脚本维护，版本与发布不属于本专项。
