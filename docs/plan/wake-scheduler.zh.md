# 唤醒调度器概要

状态：设计概要，未实现。

## 目标

模型注册唤醒任务后立即结束当前回合，由宿主调度器在到期时把唤醒消息投递到目标会话。
唤醒不占用模型线程、命令线程或会话线程，也不阻塞消息队列。

## 边界

```text
模型工具：只注册、取消、查询
宿主调度器：计时、持久化、到期投递
会话队列：接收唤醒消息，决定启动回合或排队
命令工具：不承担等待
```

禁止：

```text
工具内 time.sleep
每条任务一个线程 sleep
用 run_command 执行 sleep 代替叫醒
模型为了等待而保持回合不结束
```

## 组件

```text
Scheduler
  单线程定时器
  最近到期任务
  取消与关闭

JobStore
  持久化任务
  启动恢复
  幂等状态

WakeDispatcher
  到期任务转成唤醒消息
  投递到目标会话队列
```

job_id

due_at

```

status:

```

## 工具契约

```text
task_sleep
  seconds
  reminder
  → 返回 job_id，不阻塞

task_schedule
  at
  reminder
  → 返回 job_id，不阻塞

task_wake_cancel
  job_id

task_wake_list
  target_cid
```

时间参数必须显式校验：

```text
延迟必须大于 0
绝对时间必须带时区，或按宿主本地时区解释
已过期的时间不允许静默改成立即执行
```

## 到期投递

```text
Scheduler 到期
  ↓
原子标记 claimed
  ↓
组装唤醒消息
  ↓
目标空闲：启动新回合
目标忙碌：进入目标队列
  ↓
标记 delivered
```

唤醒消息保持独立条目，不合并成另一条。
目标忙碌时，多条唤醒在下一个安全模型轮次分别投递。

## 持久化

```text
任务落盘
原子写
启动加载
过期任务只补投一次
job_id 幂等
损坏任务留诊断，不阻塞其余任务
```

目标会话不存在、已删除，或所属父会话失效时，任务标记 failed，不无限重试。

## 并发

```text
一次只有一个调度线程
不按任务创建线程
定时器只等待最近到期时间
投递不持有会话锁
取消与到期竞争由状态机裁决
```

## 重启

```text
加载未完成任务
已过期且未投递：补投一次
已投递：不重复
已取消：不复活
```

## 与现有队列的关系

```text
唤醒是系统来源的独立消息
普通消息仍在回合结束时投递
插入消息仍在下一个安全模型轮次批量注入
唤醒不改变插入消息的独立条目语义
```

## 失败与诊断

```text
任务时间非法
目标会话不存在
目标队列拒绝
任务文件损坏
调度器关闭时有未完成任务
```

以上失败必须留下任务 id、目标 cid 和错误原因，不静默丢弃。

## 验收

```text
注册后工具立即返回
到期前模型回合已结束
到期后目标会话被叫醒
忙碌目标不阻塞其他消息
多条唤醒分别成为独立消息
重启后未到期任务继续生效
重启后已投递任务不重复
取消后不再投递
```

## 非目标

```text
不实现 cron 周期任务
不实现跨进程调度
不实现模型主动阻塞等待
不替代普通会话队列
```
