## 本版版本号

`v0.2.0`

## 本版变更

### 插件 2.0 装配

- 增加启动插口树、SlotTree/SlotRegistry、动态插口与默认实现绑定
- 增加插件装配覆盖、工具/UI/设置/路由/事件贡献登记与卸载回滚
- 拆分 boot、host、shell、tool 组件和运行期插口
- 完善 PluginContext、插件路径、插件设置树、UI 树和会话门控
- 调整上下文源、提示词章节、请求尾部和工具管道接入方式

### AI 角色扮演

- `ai_speak` 更名为 `ai_cosplay`，工具名改为 `ai_speek`
- 人物身份迁入 `plugin-config.ini`
- 设置页改为表单，支持多行身份配置
- 播放器增加 pending 状态，支持滚动重启和媒体错误重试
- 标题生成失败时使用用户消息兜底

### 推理与界面

- 推理档位增加 `low`，支持 `low / high / max`，默认 `high`
- 思考深度按钮显示当前档位
- 修复极简模式下后台任务与子智能体面板背景
- 修复思考深度菜单被字幕覆盖
- 设置页异步请求增加当前视图校验，避免旧响应覆盖当前标签
- 压缩摘要按 Markdown 展示，压缩指令强制 `##` 标题与 `-` 条目

### 认证与启动

- 已登录页面每小时调用 `/auth/status`，服务端重新下发会话 Cookie
- GUI 启动时检测旧 AI Agent 占用端口，强制结束进程树后重启
- 关闭 GUI 窗口时先停止 Web 服务，再销毁窗口
- 登录页使用自定义空密码校验，错误提示位于输入框下方
- 环境信息加入 Python 与 Node 版本，移除独立 `env_probe` 工具

### 工程

- 工具总数调整为 67
- 新增端口清理模块及独立测试
- 更新 catalog、工具文档、测试和复杂度文档

## 修复与兼容性影响

- `ai_speek` 替代旧工具名；仍引用 `ai_speak` 的外部配置或脚本需要改名
- `env_probe` 已移除；需要环境信息时使用系统提示词中的操作系统、Python、Node 和会话信息
- 默认推理档位为 `high`；已有会话保存的 `max` 或 `low` 继续生效
- 已落盘的旧压缩摘要保持原内容，下一次压缩才会按新 Markdown 规则生成
- 会话 Cookie 采用每小时滑动续期；服务进程重启会使内存会话失效，需要重新登录
- 现有 `data/` 会话记录格式保持兼容；旧插件名 `ai_speak` 的配置需迁移为 `ai_cosplay`

## 升级注意事项

- 升级前备份 `data/` 与 `plugins.ini`
- 将 `plugins.ini` 中的 `ai_speak` 插件项迁移为 `ai_cosplay`
- 升级后重启 GUI 或 Web 服务，使新前端资源和认证逻辑生效
- 首次启动如出现登录页，使用现有访问密码登录
- Python 版本要求仍为 3.10+
- 发布包必须包含本文件 `docs/releases/v0.2.0.md`，否则 `release.yml` 会拒绝创建 Release
