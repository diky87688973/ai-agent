## 本版版本号

`v0.2.1`

## 本版变更

### 插件 2.0 声明式装配与热插拔

- 统一通过插件身份文件、插口片段和工厂声明装配贡献，移除旧注册通道与重复清单
- 支持插件启用、禁用、配置应用、源码重载和目录移除后的资源撤回
- 活跃回合与插件请求结束后再应用变更，避免执行中释放资源
- 装配失败时恢复旧运行代；设置页显示待应用、成功或失败状态与具体原因
- 修复连续排队卸载可能恢复已卸载插件的问题
- 修复默认开启的 Web UI 插件关闭后无法重新启用的问题

### 会话、上下文与后台任务

- 修复新建子智能体标签在刷新或重启后无法恢复内容的问题，关闭标签同步清除前端记录
- 增加子智能体连续忙碌时长展示，完善后台任务完成通知的排队、去重与投递
- 唤醒任务隔离普通会话历史，保留当前任务所需的系统与插件提示
- 优化压缩摘要与近期完整轮次的保留策略，增加上下文用量圆环
- 模型连接在首个流式片段前断开时支持有限重试
- 单次文件替换的内容行数与目标跨度均限制为 120 行

### 界面与启动

- 优化用户确认面板的日间配色、选项和按钮样式，统一日夜模式尺寸
- 修复极简模式设置保存按钮背景与当前会话标签高亮
- 修复启动控制台中文乱码，完善启动输出编码处理

### 工程与安全

- 收紧目录浏览边界，防止超出允许文件系统范围
- 主动内容媒体按纯文本返回，并禁止浏览器 MIME 嗅探
- 完善循环依赖检查、门禁超时处理与测试网络请求检查
- 覆盖率统计纳入插件与工程脚本，修复全新检出与 Python 3.10 环境的 CI 问题
- 插件 2.0 专题文档合并为插口协议、实现与验证两份，移除已完成的交接过程文档

## 修复与兼容性影响

- 插件自有贡献与资源支持热插拔；内核及宿主实现的更换需要重启生效
- 自定义插件须使用当前声明式协议，旧注册接口不再保留
- 本次不迁移旧格式的子智能体标签记录；新建标签按新格式保存与恢复
- 延迟配置应用失败时保留已保存配置，运行时继续使用旧代，界面明确提示应用失败
- `extend / wrap` 的组合装配尚未实现，不属于本次可用能力

## 升级注意事项

- 升级前备份会话数据与插件配置；认证凭据按原有安全规则单独保管
- 升级后重启 GUI 或 Web 服务，并刷新页面以加载新前端资源
- 自定义插件升级前核对 `docs/plan/plugin-slots-protocol.md`
- 旧格式子智能体标签无法恢复时，关闭旧标签并重新打开对应子会话
- Python 版本要求仍为 3.10+
