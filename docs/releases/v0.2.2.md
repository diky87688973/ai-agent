## 本版版本号

`v0.2.2`

## 本版变更

### 升级配置合并

- 修复旧插件清单缺少 `plugin:ai_cosplay` 等新增配置节时，升级报 `No section` 并中断的问题
- 新增配置节及键正常补入，已有用户值和自定义配置保持保留
- 更新配置合并支持 UTF-8 BOM

### 更新事务与恢复

- 更新请求及暂存由实际执行切换的 helper 清理，避免引导进程重复清理
- 复制失败并成功恢复备份后，记录 `rolled_back`，不再遗留 `switching`
- 回滚失败时保留请求、暂存及切换状态，并明确记录失败原因
- 启动恢复同时检查安装版本和健康状态，避免将仍在运行的旧版本误判为升级成功
- 找不到回滚备份时明确报错，不再声称回滚成功

### Windows 启动器

- 停止旧启动器时同时匹配根目录与归档路径，修复启动器改名后无法识别旧进程的问题
- 增加正在运行的启动器改名归档、停止进程及清理归档的实际 Windows 回归

## 修复与兼容性影响

- 本版修复 v0.2.1 更新器缺陷，不改变插件 2.0 的声明式装配和热插拔协议
- 保留已有插件开关、配置值与自定义键，不要求手工补齐新增配置节
- 从旧版本首次升级时，旧引导进程仍可能打印一次 `apply.json` 已不存在的清理日志；应结合新 helper 的 `apply_success` 与 `healthy` 状态判断结果

## 升级注意事项

- v0.2.1 升级失败后，优先检查并下载 v0.2.2，避免反复应用同一份 v0.2.1 更新包
- 升级前备份会话与插件配置；认证凭据按原有安全规则单独保管
- 若日志包含 `apply_rollback_failed` 或 `recover_failed`，保留 `updates/` 中的备份、状态和日志，不手工清空恢复材料
- Python 版本要求仍为 3.10+
