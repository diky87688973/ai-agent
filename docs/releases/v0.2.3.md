## 本版版本号

`v0.2.3`

## 本版变更

### 会话索引与会话续跑

- 新增事实增量索引：启动恢复只解析上次提交之后写入的后缀，不再整档重扫
- 新增有界回放读取，历史分页与 SSE 续传共用同一套索引坐标；分页锚点由 `turn_started` 决定并兼容旧的 `input_claimed`
- 单条事实超过读取上限时按 `history_slice` 分片返回，响应带 `slice` 与 `omitted`，不再整页失败
- 新增会话目录：置顶、项目归组、移动与删除；删除项目后其会话回到最近列表，不随项目一并清理
- 确认结果改由确认存储写入，受会话内 `confirmation_lock` 保护，并携带 `request_id` 校验
- 同一挂起调用只接受一次写入，重复提交返回已失效，不再重复派发回合；会话已终止时拒绝写入并保留恢复材料
- `turn_ended` 增加 `elapsed_ms`，历史回显按回合分组回填该耗时
- 侧栏会话导航拆为 `session-rail.js`，数据按目录接口取回，翻页游标由服务端给出

### 推理回传与插入中断

- 可裁剪推理的回传预算统一由上下文装配决定：`reasoning_budget_for` 询问端口，需要原样回传时置为 `-1`
- 需要全量回传的协议由适配器声明 `requires_full_reasoning`：DeepSeek 官方接口带工具时成立，Anthropic 思考模式下按预算声明
- Anthropic 移除 `strip_stale_thinking`，思考块与 `redacted_thinking` 跨轮原样回传；缺签名块跳过并留警告
- `turn_start` 不再用于裁剪 thinking，改为锚定当前用户消息，供工具往返校验
- 插入消息优先派发：压缩、模型与工具模块检测到待认领插入时让出执行权，并以 `Outcome.next` 交还调度
- 被插入打断的工具以 `input_inserted` 结束，附「因插入消息打断，本工具未执行」

### 对话可视化与插件事件

- 新增可视化插件，经 `ui-tool-shell` 的 `props.renderer` 声明渲染能力，支持面板修订、历史恢复、视图编辑、选择回传与热插拔清理
- 集成离线 Mermaid 与 Apache ECharts，提供流程、时序、统计图、进度、表格与表单控件
- 插件事件出口收拢为窄接口：插件经 `SERVICE_PLUGIN_EVENTS` 取 `PluginEventPublisher`，推送非事实 SSE 帧，壳层不点名任何插件
- 清理旧装配入口与过期文档

### 配置、界面与工具

- 新增 `reread_after_edit` 配置项，默认关闭且可热更新；关闭时不累积待重读，移动提交按 `moved_from` 销掉源标记
- 设置页增加「编辑后要求重读」复选框，保存后推送到已有会话
- 流式渲染节流改由流式元素持有 `_streamRenderPending`，多会话并行输出不再互相打断
- 会话标题只在必要时请求：同一会话只允许一次请求在途，服务端给不出标题时不再每轮重发
- 修复目标回显串会话、启动闪窗及窗口缩放命中；窗口级 Win32 操作收拢到 `window_ops`
- 搜索统一按绝对路径排除进程根 `data`，四类工具共用 `ScanScope`，`scan_scope` 的 `skip_set` 与 `should_skip` 随之删除
- 子智能体工具声明为 `[]` 时按「全部隐藏」生效，与缺键的「不限制」区分

### 系统消息与输入渲染

- 六类系统消息统一为 `【系统消息-类型】` 加两个换行：定时唤醒任务 / 后台任务 / 视觉帧 / 记忆摘要 / 目标续跑 / 子智能体消息
- 界面渲染前剥离前缀，系统标识不向用户展示；子智能体消息先剥前缀再按 `[from=` 包装头提取元数据
- 历史回显与实时输入合并到 `renderConversationInput` 单一入口，附件条与图片丢失提示随之统一
- 系统通知与定时提醒改走通知卡片：去掉悬浮层与 6 秒自动消失，改为对话流内联；唤醒消息标题为「定时提醒」
- 输入项携带 `in_turn` 与 `goal_limit`，历史折叠可按回合归属还原输入

### 语音与稳定性

- 语音文本校准加入「去重」→「去 chóng」，与「重跑」「运行」「行数」的既有多音字处理并列
- 序列库初始化改为进程内按路径只做一次，建表与水位写入幂等，WAL 切换退避重试，修复并发首用时的 `database is locked`

## 修复与兼容性影响

- 不改变插件 2.0 的声明式装配与热插拔协议；可视化插件按既有插口接入，停用后其上下面板与脚本一并清理
- 会话索引为新增旁路，原始日志仍是唯一权威来源；旧日志无需迁移，缺少索引时按原路径读取
- `reread_after_edit` 为新增配置键，默认关闭，行为与升级前一致
- 更新器与配置合并逻辑沿用 v0.2.2，本版不含更新器改动
- 系统消息前缀改为统一形式，旧日志中的旧前缀不做兼容：按原文加载，由模型自行理解
- 镜像同步工作流改走 HTTPS 令牌，不再依赖 22 端口与 `known_hosts`
- 子智能体工具声明为 `[]` 时按「全部隐藏」生效，与缺键的「不限制」区分

## 升级注意事项

- 升级前备份 `data/` 与 `plugins.ini`；插件开关、配置值与自定义键均保留
- 首次启动会建立会话索引，会话较多的安装首次进入历史可能出现短暂「正在整理会话列表」，属正常状态
- 可视化插件依赖包内离线资源，升级后如面板空白，先确认插件为启用状态再重新打开面板
- 系统通知与定时提醒现在以通知卡片内联在对话流里，不再顶部悬浮与自动消失
- Python 版本要求仍为 3.10+
- 发布包必须包含本文件 `docs/releases/v0.2.3.md`，否则 `release.yml` 会拒绝创建 Release
