## 本版版本号

`v0.2.4`

## 本版变更

### 本地出图插件

- 新增 `image_gen` 工具，提供 `generate` / `check` / `download` / `status` 四个动作；下载与出图都是长耗时操作，一律挂宿主既有的后台任务服务并立即返回，完成后由通知触发 `status` 取结果
- 模型清单随 `check` 返回，含下载体积、建议显存、镜像源与是否需要授权；本机没有就位模型时返回 `needs_setup` 并附清单与本机显卡建议
- 下载必须先取得用户明确同意：`confirmed` 不为 `true` 时直接拒绝；需要授权的仓库返回 `needs_auth` 并列出可匿名下载的替代项，不静默换模型
- 出图与下载由 `runtime_python` 指向的解释器起子进程执行，主进程不加载扩散依赖
- 任务索引按 `task_id` 记录结果文件位置，落在宿主经 `ctx.data_dir` 注入的运行态目录，只保留最近 200 条并自动淘汰旧条目
- 配置唯一来源是插件目录的 `plugin-config.ini`；`download` 把用户确认的安装目录与该次选择的模型写回同一份配置
- 新增设置页配置项（`settings-schema.json`）、插件 UI 片段与子系统文档 `docs/subsystems/image-gen.md`

### 图片与文件卡片

- 文件卡片中的图片按 `data-file-image` 标记交给图片预览，与行内图片共用同一套 lightbox，不再另开标签页
- 预览入口归位 `image-lightbox.js`（`AIA.openImageFromPath`），输入框模块只做分派；`AIA` 未就绪时回落到文件标签页
- 文件卡片对图片类型的说明文案改为「点击看大图」，其他类型保持「在侧边栏预览」

### 差异面板

- diff 行改为不折行显示，容器改为横向滚动，复制内容不再带多余换行
- 工具自定义视图里的 diff 容器同步为横向滚动，长行不再被裁掉

### 语音与稳定性

- 多音字表补充「行内」的读法

### 工程与发布

- 复杂度文档按新增插件与函数增量重新生成
- 镜像同步工作流在推送 Tag 前取回附注 Tag 对象，标签描述不再因 checkout 的精确拉取而丢失

## 修复与兼容性影响

- 不改变插件装配协议与插口声明；`image_gen` 按既有 `tool` 插口接入，`plugins.ini` 新增 `[plugin:image_gen] [enabled = 1]`
- 其余插件的配置键与行为不受影响；`image_gen` 的 `plugin-config.ini` 入库为空模板，与其他插件配置一致
- 主进程侧新增 `requests` 依赖，由 `plugins/image_gen/requirements.txt` 声明；`torch` / `diffusers` / `transformers` / `safetensors` / `accelerate` / `gguf` 只装在 `runtime_python` 侧
- 未配置模型目录或没有就位模型时，工具返回 `needs_setup`，不影响其他能力
- Python 版本要求仍为 3.10+

## 升级注意事项

- 升级前备份 `data/` 与 `plugins.ini`；插件开关与自定义配置值均保留
- 使用出图能力前，先在插件设置页填写模型安装目录与 `runtime_python`，再用 `download` 下载权重；首次下载需要用户确认
- FLUX.1-dev（含社区量化版）为非商用许可，商用请改用 FLUX.1-schnell（Apache-2.0）或 SDXL base（OpenRAIL++）
- 显存低于清单建议值的机器上，出图子进程会报错并落结果文件，`status` 返回 `failed` 与原因
- 发布包必须包含本文件 `docs/releases/v0.2.4.md`，否则 `release.yml` 会拒绝创建 Release
