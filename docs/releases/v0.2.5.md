## 本版版本号

`v0.2.5`

## 本版变更

### 停止与模型传输

- 模型请求改为独立进程传输：新增 `agent/mechanisms/model_http/`（client / pool / process / transport / wire / worker），承担限额、FIFO 等待、取消、IPC 与回收；建连、DNS、TLS 与响应头等待都能被强制终止
- 新增 `agent/core/stream_control.py`：模型流用有界队列隔离阻塞读取，取消时登记传输终止动作，不再反推响应对象的私有 socket
- 停止改为异步清理：`/api/chat/stop` 立即返回受理状态与 `stop_id`，客户端带 `stop_id` 轮询到终态；同步调用方走 `request_cancel(cid, timeout=)`，超时抛 `StopWaitTimeout` 并保留操作标识可继续查询
- 后台任务增加 `cancel_all` 与会话级终止确认；未确认终止的进程保留运行态并抛 `TaskTerminationError` 供重试
- 前台进程强杀改为返回系统确认，未确认的进程保留登记并抛 `ShellTerminationError`
- 运行登记改用 `GetExitCodeProcess == STILL_ACTIVE` 判定存活，不再仅凭句柄是否打开
- 新增 `[model_http]` 配置节：`max_workers` / `max_pending` / `wait_timeout` / `idle_timeout`，出现未知键直接拒绝启动

### 窗口

- Windows 拖到鼠标所在屏幕工作区顶边 8 个原生像素内松手最大化；顶部任务栏区域同样可触发
- 窗口样式补 `WS_MINIMIZEBOX` 与 `WS_SYSMENU`，任务栏图标支持激活与最小化，不添加系统标题栏或缩放边框
- 移动请求串行化，松手先补齐最后一次位置再执行最大化；`dragEpoch` 让旧手势与迟到的屏幕查询失效
- 屏幕查询失败或移动失败时不触发贴顶最大化，错误留痕；macOS / Linux 不启用贴顶判断

### 语音与读音

- 「重」默认读 `chóng`（重绘、重试、重建、重启、双重），读 `zhòng` 的词族先占位保护（重要、重点、严重、尊重、重量、很重等）；去掉「重跑」「去重」两条专用替换，由统一规则承担同样输出
- 多音字表补充「数行」按行数读 `háng`

### 界面

- 更新按钮显示目标版本号
- 深色主题下项目下拉选项跟随配色

### 工程与发布

- 插件配置一律移出仓库，`plugins.ini` 不再入库
- 常规模型收尾不再写入错误日志
- 网络隔离门禁覆盖子进程：模型 HTTP 工作进程经测试启动器检查 DNS 与连接

## 修复与兼容性影响

- `/api/chat/stop` 契约变化：首次调用返回 200 或 202 与 `stop_id`，客户端需带 `stop_id` 轮询；旧页面把 202 当成功处理，停止仍会执行，但不会显示清理进度
- 新增 `[model_http]` 配置节；旧配置缺该节时取默认值，未知键拒绝启动
- 每个在途模型请求占用一个工作进程，`max_workers` 默认 8；`dispose()` 随宿主装配释放
- `plugins.ini` 移出版本库，升级不覆盖本地文件
- 不改变插件装配协议；新增 `app/host/services/model_http_pool` 静态插口，provider 经该插口取宿主池
- Python 版本要求仍为 3.10+

## 升级注意事项

- 升级前备份 `data/` 与 `plugins.ini`；插件开关与自定义配置值均保留
- 若曾把 `plugins.ini` 提交入库，升级后以本地文件为准
- 停止按钮需要新前端；旧页面缓存可能表现为点了停止没有清理进度提示
- `max_workers` 与机器进程、内存容量相关，提高前先压测
- 发布包必须包含本文件 `docs/releases/v0.2.5.md`，否则 `release.yml` 会拒绝创建 Release
