## 本版版本号

`v0.2.6`

## 本版变更

### 语音合成独立成插件

- 新增 `plugins/tts` 插件，承接 `ai_cosplay` 的合成能力
- 新增 `agent/common/tts_contract.py`：`TTSRequest` / `TTSResult` / `TTSCapabilities` 与 `TTSProvider` 协议
- 新增 `agent/common/process_guard.py`：工作对象采用 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`，宿主退出连带终止子进程
- 新增 `plugins/tts/pinyin.py`：多音字改写，仅 edge 引擎调用
- 删除 `plugins/ai_cosplay/provider.py`
- 迁移 `runtime_worker` 至新契约

### 音色工作台

- 新增右侧面板「音色工作台」，六维拼装：性别声线、年龄、音质、性格、语速、情绪
- 新增试听、命名保存、启用与删除四个操作
- 新增 `voice_id` 作为音色唯一标识，上游只传 id
- 新增按文本派生的默认种子，试听与保存共用同一 seed
- 新增标签性别标注：仅女、仅男、通用
- 新增标签过滤：按当前性别隐藏互斥标签，已选但被隐藏的值替换为同组首个可见项
- 新增男声措辞映射：男声档位下年龄档位改用对应男性措辞
- 修复启用音色需重载插件：写配置后同步 provider 运行态

### 配置开关类型

- 收紧布尔配置：读取只接受 `0` / `1`，其余写法判为配置错误
- 收紧布尔写入：只接受真布尔，产出 `0` / `1`
- 统一三条读取路径的取值类型：字段视图、按节视图、宿主设置项
- 统一两条保存路径的校验与写后回读
- 修复数字字段下发文本：改下发整数
- 修复界面开关恒为关闭：取消后端布尔值到字符串的转换
- 修复开关缺省值判错：缺省按 `0` / `1` 解析
- 新增写后回读：写入与提交不一致时返回带字段名的错误

### 插件开关

- 新增依赖级联停用：关闭被依赖插件时，按 `plugin-slots.json` 的 `requires` 一并停用依赖方
- 修复插件开关回滚不完整：回滚以原始清单为基准

### 语音不可用引导

- 新增状态字段：区分配置引擎与实际引擎，给出降级原因与安装提示
- 收紧兜底开关语义：关闭时装配失败不再换引擎
- 迁移安装引导文案至 tts，`ai_speek` 原样透传
- 新增报错指令：要求模型先调 `user_confirm` 给出三个选项，再按选择执行

### 工程与发布

- 移出版本库：`plugins/tts/plugin-config.ini`

## 修复与兼容性影响

- 插件装配协议不变；`tts` 提供 `app/plugins/tts/service` 运行时节点，`ai_cosplay` 声明 `requires.tts`
- `fallback_to_edge` 关闭时装配失败不再换引擎
- 布尔配置项只接受 `0` / `1`，其它写法拒绝装载
- 删除 `plugins/tts` 的语速配置，语速由 `ai_cosplay` 的 `speed` 决定
- 语速在 edge 引擎由合成侧应用，在本地引擎由播放侧变速，两条路径不叠加
- 音色工作台在 edge 引擎下不可用
- Python 版本要求 3.10+

## 升级注意事项

- 备份 `data/`、`plugins.ini` 与各插件 `plugin-config.ini`
- 布尔项取值改为 `0` / `1`，其它写法会导致插件拒绝装载并在状态里给出键名
- 关停 `fallback_to_edge` 的安装，本地引擎不可用时合成报错
- 音色工作台需要配置「模型安装目录」
- `plugins/tts/plugin-config.ini` 不随包覆盖本地文件
- 发布包必须包含本文件 `docs/releases/v0.2.6.md`
