## 本版版本号

`v0.2.6`

## 本版变更

### 语音合成独立成插件

- 新增 `plugins/tts` 插件：合成能力从 `ai_cosplay` 剥离，经 `agent/common/tts_contract.py` 的 `TTSRequest` / `TTSResult` / `TTSCapabilities` 与 `TTSProvider` 协议对接；上游只表达音色、情感与语速诉求，不再持有引擎概念
- 本地模型优先，`breeze` 引擎经本地服务合成；`edge` 引擎作网络方案，`fallback_to_edge` 控制本地不可用时是否回落
- 新增进程守护 `agent/common/process_guard.py`：工作对象采用 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`，宿主退出时连带终止本地模型进程
- 多音字改写随合成迁入 `plugins/tts/pinyin.py`，仅 edge 引擎调用
- 删除 `plugins/ai_cosplay/provider.py`；`runtime_worker` 改用新契约，进程守护与队列语义不变

### 音色工作台

- 新增右侧面板「音色工作台」：按年龄、音质、性格、语速、情绪五维拼装，配合性别声线共六维；支持试听、命名保存、启用与删除
- 音色以 `voice_id` 为唯一标识，上游只传 id；`voice_id` 为空且非设计模式时回退到配置的默认音色
- 试听使用 `design=True` 走指令造音色，不复用参考音色，否则任何组合都会锁死在同一段音色上
- 同一句指令加同一 seed 生成结果完全一致，试听与保存共用同一个由文本派生的种子
- 启用音色当场生效：写配置后同步 provider 运行态，不再要求重载插件
- 切换性别时按标签标注过滤：仅女、仅男、通用三种；互斥标签隐藏，已选但不可见的值换成同组首个可见项，避免出现「青年 + 少女」这类组合
- 男声档位下年龄档位改用对应男性措辞，避免 `a young woman` 与 `male` 互相抵消

### 配置开关的类型契约

- 布尔值在 ini 边界统一用 `0` / `1`：读取只认这两种写法，其余直接报配置错误；写入只接受真布尔，不产出其它形式
- 设置页三条读取路径（字段视图、按节视图、宿主设置项）与两条保存路径统一转类型，数字字段下发整数而非文本
- 界面开关只认 `true`，不再把后端布尔转成字符串；缺省值下发前也转成布尔
- 插件配置保存增加写后回读：写入与提交不一致时返回带字段名的错误，不再出现「界面显示已保存、文件里还是旧值」

### 插件开关

- 关闭被依赖的插件时，按各插件 `plugin-slots.json` 的 `requires` 找出依赖方一并停用，不再出现「插件关不掉、只报请求失败」
- 插件开关回滚以原始清单为基准，多节写入不会只回滚一半

### 语音不可用时的引导

- 状态区分配置引擎与实际引擎，并给出降级原因与安装提示；关闭兜底后装配失败不再静默改用 edge，合成时如实报错
- 安装引导文案归 tts 所有，`ai_speek` 只原样透传，不自造措辞
- 报错改为对模型的强指令：必须先调用 `user_confirm` 征求用户选择（现在安装本地模型 / 改用 Edge 在线合成 / 暂不处理），选定后分别执行安装或开启兜底

### 工程与发布

- `plugins/tts/plugin-config.ini` 移出版本库，与其它插件一致；本地文件不受影响

## 修复与兼容性影响

- 插件装配协议不变；`tts` 作为独立插件提供 `app/plugins/tts/service` 运行时节点，`ai_cosplay` 声明 `requires.tts`
- `fallback_to_edge` 语义收紧：关闭时装配失败不再换引擎。此前关闭该开关仍可能静默使用 edge
- 布尔配置项只接受 `0` / `1`：写成 `true`、`yes` 等会被判为配置错误并拒绝装载，需按提示改成 `0` / `1`
- 删除 `plugins/tts` 的语速配置：该键只参与状态回显，从不进入合成或播放；语速统一由 `ai_cosplay` 的 `speed` 决定
- 语速在 edge 引擎上由合成侧应用（`speed_applied=true`），在本地引擎上由播放侧变速；两种路径不会叠加
- 音色工作台依赖本地引擎：引擎为 edge 时面板不可用，属预期
- Python 版本要求仍为 3.10+

## 升级注意事项

- 升级前备份 `data/`、`plugins.ini` 与各插件 `plugin-config.ini`；插件开关与自定义配置值均保留
- 若旧配置把布尔项写成 `true` / `false` / `yes` 等，升级后插件会拒绝装载并在状态里给出键名，按提示改成 `0` / `1`
- 曾关闭「本地方案不可用时用 Edge 兜底」的安装，升级后本地引擎不可用时将直接报错，不再静默走网络合成
- 音色工作台需要配置「模型安装目录」；未配置时该面板不可用
- `plugins/tts/plugin-config.ini` 已移出版本库，升级不覆盖本地文件
- 发布包必须包含本文件 `docs/releases/v0.2.6.md`，否则 `release.yml` 会拒绝创建 Release
