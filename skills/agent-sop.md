# AGENT_SOP：界面操作与设置引导

本 Skill 用于回答用户关于界面操作、设置入口、配置修改的问题。回答时直接给出可执行的界面路径和准确控件名，不猜测不存在的入口。

## 1. 总原则

1. 先判断用户要改的是哪一类：会话操作、输入操作、显示、模型、上下文、插件、鉴权、更新。
2. 能在界面完成的，优先走界面；界面没有入口时，才说明配置文件路径。
3. 不把 `data/`、`data/auth/`、会话事实、API 密钥交给用户手工编辑；这些必须走对应入口或 CLI。
4. 不输出、复述、截图 API Key、密码、Cookie、Token。
5. 修改设置后说明是否需要保存、应用、刷新页面或重启进程。
6. 用户没有给出具体目标时，先问“要改哪一项设置”，不要一次罗列所有配置。
7. 不声称某个设置已经生效；只能说明“已保存”或让用户确认界面状态。

## 3. 会话操作

| 操作 | 界面路径 |
|---|---|
| 新建会话 | 左侧「新会话 +」 |
| 切换会话 | 左侧会话列表点击，或顶部会话页签 |
| 展开/收起会话栏 | 左侧栏顶部按钮；或对话区左上角会话清单按钮 |
| 调整会话栏宽度 | 拖拽会话栏右侧分隔条 |
| 调整对话区/步骤区宽度 | 拖拽对话区与右侧步骤区之间的分隔条 |
| 查看当前会话 ID | 顶栏会话短 ID；完整 ID 由会话页签或导出上下文获得 |

## 4. 输入区

| 操作 | 界面路径 |
|---|---|
| 发送 | 输入框下方「发送」，或 Enter |
| 换行 | Shift+Enter |
| 选择模式 | 输入框下方「Auto +」→ 默认模式 / 方案设计 / 执行计划 |
| 用斜杠切换模式 | 输入 `/Auto`、`/Plan`、`/Execute` |
| 调整推理档位 | 输入框下方「思考 · High/Max」 |
| 选择模型 | 输入框下方模型下拉；模型由「设置 → 模型」配置 |
| 关联文件 | 输入 `@` 选择文件或目录 |
| 添加图片 | 左侧图片按钮；或 Ctrl+V 粘贴图片 |
| 删除待发送图片 | 图片缩略图右上角关闭按钮 |
| 停止当前任务 | 输入框下方「停止」 |
| 设定持续推进目标 | 输入框下方「目标」→ 填写文案 → 保存；可暂停、恢复、标记达成、删除 |

## 5. 消息区与工具

| 操作 | 界面路径 |
|---|---|
| 展开工具详情 | 点击工具卡标题 |
| 展开工具输出/参数 | 工具卡内的分段标题 |
| 查看图片 | 点击消息附件，打开图片查看器 |
| 加载更早历史 | 消息区滚到顶部；出现「加载更早的对话…」 |
| 回到最新消息 | 输入框外侧的向下箭头；不在底部时出现 |
| 查看上下文占用 | 左侧栏底部模型用量/上下文占用 |
| 查看步骤明细 | 右侧「步骤」页签 |

## 6. 队列与并行任务

| 操作 | 界面路径 |
|---|---|
| 查看待发送队列 | 输入框上方「消息队列」 |
| 插入到当前回合 | 队列行的「插入发送」按钮 |
| 修改排队消息 | 队列行的「修改」按钮；内容会回到输入框 |
| 取消排队消息 | 队列行的「取消」按钮 |
| 查看子智能体 | 输入框上方「子智能体」标题栏；点击展开清单 |
| 查看后台任务 | 输入框上方「后台任务」标题栏；点击展开清单 |
| 刷新后台任务 | 任务清单中的「刷新」 |
| 查看任务输出/详情 | 任务行点击展开详情 |

## 7. 设置入口

顶栏右侧齿轮按钮打开「设置」。导航按用途分组：

```text
Agent
上下文
界面
模型（多模型插件启用时）
插件
  AI说话（ai_speak）
  知识库（knowledge）
  多模型（multi_model）
  Rules（rules）
  Skills（skills）
  Visual Operator（visual_operator）
```

已启用且可配置的插件会直接显示对应配置页；未启用或不可配置的插件在「插件」页通过卡片开启或查看。AI 引导时以用户当前实际看到的标签为准；用户看不到配置页时，先引导到「插件」页启用。

插件目录与显示名对应：

| 插件目录 | 显示名 |
|---|---|
| `ai_speak` | AI说话 |
| `knowledge` | 知识库 |
| `multi_model` | 多模型 |
| `rules` | Rules |
| `skills` | Skills |
| `visual_operator` | Visual Operator |

底部按钮：

```text
保存：写入并关闭设置
应用：写入但保持窗口打开，便于继续修改
```

保存失败或“已写入但生效失败”时，把界面显示的原因原样告诉用户，不要自行改文件绕过。

## 8. 宿主设置

### Agent

| 字段 | 作用 | 注意 |
|---|---|---|
| 推理档位 | high / max | 影响模型推理强度与成本 |
| 每回合往返上限 | 单回合最多模型往返次数 | 不是工具调用次数；每次往返可调用多个工具 |
| AI 修改文件时的备份保存天数 | 文件备份保留时间 | 0 表示不保留 |

### 上下文

| 字段 | 作用 |
|---|---|
| 压缩时保留最近对话轮数 | 自动压缩时保留的最近完整轮次 |
| 摘要字数上限 | 压缩摘要的输出上限 |
| 思维链回传预算 | 历史思考内容回传预算 |
| 带图用户轮数 | 请求中回放最近多少个带图用户轮 |
| 带图张数上限 | 单次请求最多携带的图片数 |

### 界面

| 字段 | 作用 |
|---|---|
| 工作区展示工具步骤 | 对话区是否展示工具执行步骤 |
| 侧边栏展示工具步骤 | 右侧步骤栏是否展示工具步骤 |

## 9. 插件设置

打开「设置 → 插件」。

| 操作 | 界面路径 |
|---|---|
| 启用/停用插件 | 插件卡片右侧开关 |
| 编辑插件配置 | 卡片上的「设置」；只有可配置插件才显示 |
| 查看插件说明 | 卡片标题与描述 |

启停插件会改变工具、面板、上下文注入和快捷入口。保存插件配置后，告诉用户刷新或重新打开相关面板确认。

## 10. 模型设置

路径：「设置 → 模型」，或在「设置 → 插件 → 多模型 → 设置」。

| 操作 | 控件 |
|---|---|
| 新增模型 | 「添加模型」 |
| 删除模型 | 模型配置条目内的删除按钮 |
| 设置默认模型 | 条目的 `default` 标记 |
| 协议 | `provider`：OpenAI（Chat Completions）/ Anthropic（Messages） |
| 网关地址 | `base_url` |
| API 密钥 | `api_key`；已配置时只显示占位提示，不回显明文 |
| 模型名 | `model`，必须与供应商一致 |
| 显示名称 | `label` |
| 最大上下文窗口 | `context_window`，压缩阈值计算的必填项 |
| 压缩阈值 | `compression_percent` |
| 回复上限 | `max_tokens` |
| 深度思考 | `thinking` / `thinking_budget_tokens`，按供应商支持情况填写 |

修改模型配置后，让用户确认模型下拉是否出现新条目；不要在回复中展示密钥。

## 11. 知识库设置

路径：「设置 → 知识库配置」，或「设置 → 插件 → 知识库 → 设置」。

| 字段 | 作用 |
|---|---|
| 目录 | 知识库根目录；可点「选择目录」 |
| 单文件上限（字节） | 超过上限的文件跳过 |
| 额外扩展名 | 未被默认识别的文本后缀，逗号分隔 |

未配置目录时，资源目录会显示：

```text
- 知识库: 未配置
  当前未配置知识库目录，必要时提醒用户去"知识库"插件中配置dir
```

配置后让用户打开知识库面板刷新，并勾选要注入当前会话的文件。

## 12. Skills 设置

路径：「设置 → Skills 配置」，或「设置 → 插件 → Skills → 设置」。

| 字段 | 作用 |
|---|---|
| 目录 | 外置 Skills 根目录；可点「选择目录」 |
| 单文件上限（字节） | 单个 Skill 文件上限 |

内置 `skills/` 始终加载；外置目录只影响用户 Skills。修改后让用户刷新 Skills 清单。

## 13. Rules

Rules 没有设置表单，规则文件位于：

```text
rules/*.md
rules/USER_RULES.md
```

每个 `.md` 会作为系统规则注入。指导用户直接编辑规则文件，不要让用户修改 `data/`。

## 14. AI说话与视觉操作

这两类插件当前没有独立设置页，只有插件启停开关。

| 插件 | 配置位置 |
|---|---|
| AI说话 | `plugins/ai_speak/plugin-config.ini` |
| 视觉操作 | `plugins/visual_operator/plugin-config.ini` |

需要改音色、语速、截屏开关等参数时，说明这是插件配置文件，修改后通常需要重启服务。不要引导用户改密钥或运行态文件。

## 15. 鉴权

鉴权没有普通设置表单。

| 目标 | 入口 |
|---|---|
| 设置访问密码 | `agent-web --set-password` |
| 签发 API Token | `agent-web --issue-token NAME --scope read,chat` |
| 撤销 Token | `agent-web --revoke-token NAME` |
| 查看鉴权模式 | `config.ini` 的 `[auth]`；不要让用户手工改 `data/auth/` |

涉及密码、Token、TLS、公网绑定的修改，提醒用户重启服务并确认登录仍可用。

## 16. 更新与主题

| 操作 | 界面路径 |
|---|---|
| 检查更新 | 顶栏「更新」按钮（有更新时显示） |
| 切换白天/夜间 | 顶栏「白天模式」/「夜间模式」 |
| 更新安装 | 按更新界面提示；不要在回复中承诺未执行的更新结果 |

## 17. 引导模板

用户说“改设置”但没有说具体项时：

```text
可以。请告诉我你要改哪一项：
模型/API、知识库目录、Skills 目录、界面显示、上下文压缩、插件启停、鉴权或更新。
```

用户说“改模型”时：

```text
设置 → 模型 → 选择模型条目修改；新增用「添加模型」。
填完后点「保存」；API 密钥留空表示不修改已有密钥。
```

用户说“知识库没生效”时：

```text
设置 → 知识库配置，确认「目录」已选且文件未超过单文件上限；
保存后打开知识库面板刷新，并勾选要注入当前会话的文件。
```

用户说“Skills 在哪里加”时：

```text
设置 → Skills 配置 → 目录 → 选择目录；
内置 skills/ 不需要配置，外置目录保存后刷新 Skills 清单。
```

## 18. 禁止事项

```text
不编造不存在的设置项或按钮
不把 API Key、密码、Token 粘贴到回复或截图
不让用户直接编辑 data/、data/auth/、会话事实文件
不只说“去设置里改”，必须给出具体设置节和字段
不承诺设置已生效，除非用户确认或配置接口返回成功
不在未说明影响范围时建议停用插件、重启服务或修改公网鉴权
```
