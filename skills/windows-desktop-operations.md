# Windows 常规操作

先做系统级操作，把目标窗口带到前台或把应用打开；再用视觉操作定位具体控件。

## 0. 选择顺序

```text
1. 能键盘完成 → 键盘
2. 能激活窗口完成 → 先激活，不盲点窗口内容
3. 能通过开始菜单、搜索、运行框打开 → 系统入口
4. 目标位置必须看图 → 视觉移动 + 点击
5. 动作后必须看新帧确认结果
```

视觉坐标只负责最后落点，不能代替窗口激活、应用启动和菜单选择。

## 1. 激活窗口

### 1.1 Alt+Tab 轮换

```text
vision_key(keys=["alt", "tab"])
```

一次调用轮换一个前台窗口。每轮后看画面确认标题栏和内容，未到目标继续调用。

反向轮换：

```text
vision_key(keys=["alt", "shift", "tab"])
```

注意：工具是按下即抬起，不会持续按住 Alt。不要假设 Alt 一直保持按下。

### 1.2 按住 Alt+Tab 后点击

标准 Windows 操作：

```text
按住 Alt
→ 按 Tab 选择目标窗口
→ 保持 Alt 按住
→ 鼠标点击目标窗口
→ 释放 Alt
```

当前 `vision_key` 是一次按下即抬起，不能跨工具保持 Alt。不能持续按住 Alt 时，改用：

```text
Alt+Tab 轮换到目标
或任务栏图标 → 缩略图 → 点击窗口
```

不要假装按住 Alt；按键工具没有保持状态。

### 1.3 点击标题栏或空白区

目标窗口可见时：

```text
点击标题栏
或点击窗口内不属于按钮、输入框、列表的空白区域
```

不要点关闭、最小化、最大化按钮，也不要点输入框。

### 1.4 任务栏缩略图

步骤：

```text
1. 找到任务栏中的应用图标
2. 单击图标，等待缩略图弹出
3. 点击目标窗口缩略图
4. 看新帧确认窗口已在前台
```

图标有多个窗口时，缩略图会列出所有窗口，按标题选择。

### 1.5 任务栏图标切换

```text
点击任务栏图标
→ 如果只开了一个窗口，通常直接切到前台
→ 如果开了多个窗口，先显示缩略图，再点具体窗口
```

### 1.6 系统托盘图标

```text
单击托盘图标：打开主窗口
右键托盘图标：打开菜单
菜单中选“打开 / 显示 / 主界面”
```

托盘图标在右下角，可能藏在 `^` 展开区里。

### 1.7 Win+Tab 与任务视图

```text
vision_key(keys=["win", "tab"])
```

进入任务视图后，点击目标窗口缩略图。不要连续快速开关任务视图。

### 1.8 最小化窗口

```text
点击最小化按钮
或 vision_key(keys=["win", "down"])
```

已最小化的窗口不能直接点内容，先激活。

## 2. 打开应用

### 2.1 开始菜单

```text
vision_key(keys=["win"])
→ 看开始菜单
→ 点击应用图标
或点击“所有应用”后滚动查找
```

开始菜单没有目标时用搜索，不要盲翻。

### 2.2 任务栏搜索

```text
点击任务栏搜索框
或 vision_key(keys=["win", "s"])
→ 输入应用名
→ 点击搜索结果或用回车打开
```

搜索框要先确认已获得焦点，再输入。

### 2.3 运行框

```text
vision_key(keys=["win", "r"])
→ 等运行框出现
→ 输入命令
→ 回车
```

运行框适合：

```text
notepad
mspaint
calc
explorer
cmd
powershell
控制面板命令
已安装程序的启动命令
```

不要执行来源不明的命令，不要用命令删文件或改系统设置。

### 2.4 文件资源管理器

```text
vision_key(keys=["win", "e"])
```

打开后可在地址栏输入路径，或从左侧导航选择目录。

### 2.5 已固定到任务栏的应用

```text
Win+数字
```

按任务栏从左到右的位置打开对应应用。数字键对应第几个图标，不是应用名。

### 2.6 从桌面或文件夹打开

```text
双击桌面图标
或打开文件夹后双击目标文件
```

双击不是单击；需要双击时不要用单次 `vision_click`。

## 3. 常用键盘操作

```text
Win            开始菜单
Win+S          搜索
Win+R          运行
Win+E          文件资源管理器
Win+D          显示桌面
Win+L          锁屏
Win+Tab        任务视图
Alt+Tab        切换窗口
Alt+F4         关闭当前窗口
Ctrl+W         关闭当前标签页或窗口
Ctrl+Tab       下一个标签页
Ctrl+Shift+Tab 上一个标签页
Ctrl+L         浏览器地址栏
Ctrl+F         页内查找
Ctrl+A         全选
Ctrl+C         复制
Ctrl+X         剪切
Ctrl+V         粘贴
Ctrl+Z         撤销
Ctrl+Y         重做
Enter          确认
Esc            取消或关闭弹层
Tab            下一个控件
Shift+Tab      上一个控件
Space          勾选或按下当前控件
方向键         移动焦点或选项
PageUp/PageDown 翻页
F5             刷新
F11            全屏切换
Alt+Space      窗口系统菜单
Win+方向键     窗口贴边或最大化
```

按键前先确认目标窗口在前台。按键后看新帧，不要连续盲按。

## 4. 菜单与右键

```text
右键目标 → 看菜单 → 点击菜单项
```

菜单打开后：

```text
方向键移动
Enter 确认
Esc 关闭
```

不要点菜单外的区域来“关闭并顺便执行”，菜单外点击可能取消操作。

子菜单要悬停或点击父项展开，确认子菜单出现后再选。

## 5. 对话框与确认

```text
先读对话框标题和正文
确认按钮文字
再点击“确定 / 是 / 保存 / 不保存 / 取消”
```

不要默认点“确定”。有“不再询问”“删除”“覆盖”“格式化”等字样时停下来确认。

文件选择框：

```text
地址栏输入完整路径
或左侧导航
或文件名输入框
最后点“打开 / 保存”
```

## 6. 任务栏与通知区

```text
任务栏图标：切换、显示缩略图、右键跳转列表
系统托盘：单击主窗口，右键菜单
通知中心：Win+N 或点击右下角通知图标
输入法：Win+Space 切换
音量/网络/电源：点击右下角系统图标
```

托盘图标太小无法确认时，先展开 `^` 隐藏图标区，不要按颜色猜。

## 7. 文本输入与表单

```text
点击输入框
Ctrl+A 选中旧内容
输入新内容
Enter 或点击提交按钮
```

输入前确认光标在输入框内；输入后看新帧确认文本出现。

不要在一个输入框里连续输入多个字段；每个字段重新定位。

## 8. 浏览器与网页

```text
Ctrl+L 地址栏
Ctrl+T 新标签页
Ctrl+W 关闭标签页
Ctrl+Tab 切标签页
Ctrl+F 页内查找
F5 刷新
Alt+Left 后退
Alt+Right 前进
F11 全屏
```

页面没加载完时不要连续点击；先看加载状态。

登录、支付、删除、授权页面不要自动确认，等待用户明确指令。

## 9. 游戏与全屏应用

```text
先激活游戏窗口
确认窗口在前台
再移动和点击
```

全屏游戏切换窗口优先用 Alt+Tab，不要点任务栏后再点画面，避免焦点丢失。

倒计时场景：

```text
一次看帧取多个已确认目标
一次批量点击
点击后立即看新帧
不用旧帧坐标点下一批
```

## 10. 动作后验证

每次系统操作后检查：

```text
窗口标题是否变化
目标窗口是否在前台
菜单是否真的打开
对话框是否出现
输入框是否获得焦点
点击后页面是否变化
```

没有变化就停，不要连续重复同一个动作。

## 11. 禁止

```text
不在窗口未激活时点击窗口内容
不把光标标记当成目标
不凭颜色猜托盘图标
不连续盲按快捷键
不默认确认危险对话框
不在全屏游戏里点任务栏再点画面
不用命令删除文件、改系统设置或绕过权限
```

## 12. 与视觉操作的分工

```text
Windows 常规操作：激活、打开、切换、键盘、菜单、对话框、验证
视觉操作：看当前帧、取目标像素、移动、点击
```

先完成系统级动作，再用视觉落点；不要用视觉点击代替所有键盘和窗口操作。
